# 小羽未成年人网络环境 H5

最新版手机端 H5 源码与完整素材。页面采用手机端分屏翻页，三个家庭采访部分保留连续滚动。

本次更新替换了设备使用时长图、健康风险图和各国政策地图，并修复开头、人物介绍、卧室、教室、放学路点击或动画完成后的轻微闪动。

## 在线地址

GitHub Pages 发布后：<https://seecoldian-beep.github.io/xiaoyu-h5/>

推送到 `main` 分支后，GitHub Actions 会直接发布仓库内容，不再从旧网址覆盖同步。

## 本地预览

```bash
python3 -m http.server 8080
```

访问 <http://localhost:8080>。
